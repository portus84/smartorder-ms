# 9. Architectural Decisions

AD001 — Messaging: RabbitMQ for async events
- Rationale: mature AMQP ecosystem, reliable delivery semantics

AD002 — Persistence: MongoDB
- Rationale: flexible schema for rapid development

AD003 — Local dev: Docker Compose
- Rationale: low barrier for local onboarding and demos

(Each decision can be extended with alternatives, consequences and review date.)
