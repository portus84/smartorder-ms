# 2. Constraints

- Implemented in Java / Spring Boot (Maven multi-module).
- Local orchestration: Docker Compose (docker/).
- Persistence: MongoDB.
- Message broker: RabbitMQ (AMQP).
- Consul used in dev compose (dev-mode).
- Monitoring stack included: Prometheus, Grafana, InfluxDB, exporters.
- Repo structure and conventions must be respected when changing modules or compose files.
